# 看图写话工作台

面向小学一、二年级教师的独立看图写话批改原型。应用不包含班级、名单、账号、分数或正式报告；所有任务、图片、原文和结果仅存放在当前浏览器的 IndexedDB 中。

本项目与 `essay-grading-app` 完全独立。两者可以参考产品思路，但不得共用任务数据、OSS 路径、云函数或浏览器存储名称。云端发布步骤见 [DEPLOYMENT.md](./DEPLOYMENT.md)。

## 本地运行

```bash
npm install
npm run dev
```

开发模式下，如果未启动 AI 服务，前端会自动使用演示分析结果，方便完整体验流程。

## AI 服务分工

- Kimi：读取题图、识别图片中的印刷要求、忠实转写学生手写原文。
- DeepSeek：根据老师确认后的任务边界拆解评价点，根据确认后的学生原文逐项批改。
- 老师直接输入文字时会跳过 Kimi，直接进入 DeepSeek 批改。

要接入真实 AI：

1. 将 `.env.example` 复制为 `.env`。
2. 在 `.env` 中填写 `MOONSHOT_API_KEY` 和 `DEEPSEEK_API_KEY`。密钥只保存在本机，不要粘贴到聊天、前端代码或提交到版本库。
3. 在一个终端运行 `npm run server`。
4. 在另一个终端运行 `npm run dev`。

AI 中转服务本身是无状态的，不保存题图、学生图片、原文或批改结果。调用真实服务时，题图和作品图片会发送给 Kimi，确认后的文字会发送给 DeepSeek；模型配置和密钥不会出现在教师界面中。缺少某一家的密钥时，对应步骤会使用演示数据，`/api/health` 可以查看当前实际模式。

## 年级评价边界

- 一年级重点是“愿意说、敢于写，基本看得懂”，不强制写齐时间、人物、地点和事件。
- 二年级不增加额外学期选项。系统根据题型、明确任务和写话支架，自动判断“起步写话”或“进阶写话”。
- 单图一句、简单观察或开放表达默认是起步写话：允许一句或几句，重在主要内容清楚。
- 多图顺序、续写、仿写、表格或关键词引导的复合任务默认是进阶写话：关注完整句、意思清楚和前后能够连起来。
- 例句、表格、关键词和顺序词只是表达支架，不要求机械照抄、全部使用或按固定顺序写。
- 低年级使用拼音代替不会写的汉字属于正常表达。拼音的声调、空格或轻微拼写问题不作为错别字或语病；老师已确认的原文也不会因拼音较多而进入 OCR 核对状态。
- 只有原文中保留多个“□”等真实未识别内容，已经影响核心判断时，才暂停批改并提示老师核对原文。
- 内容理解和用字规范分开判断。像“由地园”这类结合题意与上下文可以明确理解为“邮递员”的近音错字，内容评价按“邮递员”理解，人物和事件仍可达成；原文始终保留“由地园”，并只在原词处提示订正为“邮递员”。
- 一个或少量能够理解的错别字不会改变已经达成的内容项，也不会单独降低整体结论；错字仍会在“优先修改的地方”单独订正。同一个错词重复出现时只完整订正一次，后续位置只作轻提示，不重复批评。只有语言问题已经影响理解时，才通过相应的基本评价点降低整体结论。
- “尝试使用基本句末标点”采用原文确定性判断：只要至少有一句清楚使用了句号、问号或感叹号，该项即为已达成；其他局部标点问题仍可单独提示，但不会把整项判为未达成。
- 错字订正必须以完整错词或最小词组为单位，不能脱离上下文把一个本来正确的汉字猜改成另一个汉字；例如“正当……的时候”属于正确表达，不得把“正”改成“成”。
- 可理解的儿童口语、稚拙句式和不规范词序按原意评价内容，只提醒表达可以更清楚，不改写成成人化句子。人物姓名、地名、自创称呼只有在题目或上下文提供明确标准写法时才订正。
- “错别字”“识别待核对”“表达待核对”严格分开：能够唯一理解的错字直接订正；看不清原字才属于识别问题；只有多个合理解释会实质改变评价结果时才集中请求老师核对，且不阻断其余内容批改。
- 一个评价点可以由前后多处原文共同证明。人物、办法、对象或结果分散在不同句子时，系统分别引用最多三段原文，不会因为证据不是一段连续文字就把“已达成”错误降为“未达成”。
- 系统会在任务设置中显示当前判断，老师仍在原有“评价点”环节一次确认，不新增重复流程。

## 数据说明

- 本地开发可以不设密码；云端版使用本项目专用访问密码，不与旧工作台共用登录状态。
- 不建立班级或学生名单。
- 数据不跨设备同步。
- 清除浏览器站点数据会永久删除全部任务。
- 删除任务或作品没有回收站。
- 即使与旧工作台部署在同一个 GitHub Pages 域名下，也使用独立的 IndexedDB、会话键和 API 应用标识。
- 第一版云端后端无状态且不使用 OSS；远程访问不等于跨设备同步。

npm run build
